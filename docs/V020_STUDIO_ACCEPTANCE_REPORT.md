# v0.2.0 Studio 最终验收

本机 Windows Edge 使用两个隔离探针，均通过。

| 检查 | 实测 |
|---|---|
| 常规交互 | 新建棋盘、黑白标记、撤销重做、键盘移动、行列高亮、求解、轨迹、种子生成、15×15 窄屏滚动通过。空线索谜题初始化立即显示对应满足状态。 |
| 文件 | 点击 Edge 文件控件，截获实际文件选择事件后选中磁盘文件。导出写到了下载目录，读回 JSON 逐字段相同。切换谜题后经相同文件控件重新导入已下载的文件，通过。非法 JSON 和 UTF-8 均拒绝，棋盘保持原状。 |
| 20×20 与刷新 | 通过文件导入建立 400 格，窄屏横向滚动，验证边缘按键无越界、键盘移动、填色和行列状态。刷新后返回初始棋盘、清空历史和涂色，符合当前会话行为。 |

日志在 _build/v020-r14/edge-controls.log 和 edge-files.log。磁盘运行目录包含原始及下载 JSON 和 20×20 截图。本轮用 Edge DevTools 连接实际浏览器并读写真实文件。Windows 系统选择器的人工交互、不同浏览器及移动真机仍无本轮证据。
