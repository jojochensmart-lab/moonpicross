# 人工撰写申报书的事实底稿

- 名称建议使用 MoonPicross Studio。方向是 MoonBit 生态工具库和离线谜题工作台。
- 一句话技术定位。用任意黑白数织线索做有界求解、第二解检查和可复现生成，离线 Studio 与库共享算法。
- 三个场景。应用开发者输入线索并消费有类型的求解状态；谜题创作者以尺寸、种子和算法难度筛选生成，导出后重新验唯一性；题库编辑者离线绘图、提取线索、分析并交换版本化文件。分别见 examples/solve、examples/generate 和 studio。
- 实测依据。独立 Oracle 有 15,745 组棋盘线索组合，在测试中还验证了 141 组候选域。300 个固定种子调查中，5×5 与 10×10 各 100 个成功，15×15 有 94 个成功，所有成功谜题经同一求解器另行复核。
- 原创边界。MoonBit 核心和验证代码独立实现，经典约束传播和回溯已有同类。参考项目和许可证见合规记录。
- v0.1.0 建议范围。优先 5×5 至 15×15，黑白数织，算法复杂度解释，离线使用与独立核心。暂不承诺彩色谜题、大尺寸稳定生成、主观人类难度、云端或在线账号。
- 正式仓库 URL、注册表可安装版本及 GitHub commits 数量要填写经核验的真实数据。批次日期、资格和奖励以最新正式章程为准。
