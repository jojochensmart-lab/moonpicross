核对日为 2026 年 11 月 25 日（北京时间）。下表依据任务书列出的条款建立。指定的《MoonBit 黑客松大赛章程(1).md》未在已检索的本地目录找到，仍需原件核对措辞和适用批次。

| 条款 | 状态 | 证据或动作 |
|---|---|---|
| 项目名称、简介、方向、通用性 | 已满足 | README 和事实清单已备 |
| 三个完整预期场景与核心功能 | 已满足 | 两个 CLI 示例和离线 Studio，可复跑 |
