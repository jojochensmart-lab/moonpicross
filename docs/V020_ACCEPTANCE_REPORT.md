# MoonPicross Studio v0.2.0 本地验收

基线为 main 253a51b。v0.1.0 标签、正式 Release、在线 Studio 和 Mooncakes 0.1.0 保持已发布状态。本轮验收仅针对本地代码和 0.2.0 包候选。

## 完成范围

- core/solver.mbt 按黑白掩码缓存行列分析。在传播收敛后优先对关联候选域较小的格分支，平局按行优先顺序处理。原有入口、记录构造方式和 JSON v1 保持可用。新增 solve_bounded 和可配置递归深度上限。预算耗尽仍返回 Budget，已有首解时也保留该状态。
- 15×15 及以上从第 9 次尝试起穿插带方向的结构化采样，仍用相同随机流、尝试次数和预算。每个接受样本仍须取得完整的唯一性证明。选中的棋盘、首解和难度统计可能随版本改变。
- studio/app.js、index.html 和 styles.css 增加撤销、重做、清空、键盘导航、线索高亮和匹配反馈。webapi/export.mbt 提供验证专用入口，导入只验证，不会先跑完整求解。文件以严格 UTF-8 解码。
- 新增独立唯一性例程、深度与最大棋盘边界测试、随机线索性质检查和畸形 JSON 回归。CI 加入可执行唯一性示例、生成调查和 Windows Edge 磁盘文件检查。

## 算法和生成数据

相同默认预算，每个尺寸求解 60 个固定棋盘，JS 和 Wasm GC 的确定性计数一致。

| 尺寸 | 平均节点（前 → 后） | 求解预算耗尽（前 → 后） | 生成成功（前 → 后） |
|---|---:|---:|---:|
| 5×5 | 2.00 → 1.87 | 0 → 0 / 60 | 200 → 200 / 200 |
| 10×10 | 5.72 → 4.98 | 0 → 0 / 60 | 200 → 200 / 200 |
| 15×15 | 64.95 → 49.17 | 5 → 0 / 60 | 189 → 200 / 200 |
| 20×20 | 41.63 → 113.52 | 44 → 32 / 60 | 41 → 84 / 100 |

所有 684 个生成成功样本均重新运行生成、重建并校验线索、复核唯一解和见证棋盘。20×20 有 16 个种子仍耗尽尝试。20×20 求解平均候选扫描约从 423 万降至 319 万；扫描变少让更多搜索节点能进入预算。15×15 Wasm GC 求解 P95 从 25.56 ms 降至 4.32 ms，JS 从 25.01 ms 降至 3.30 ms。5×5 Wasm GC 中位数略有上升，单次时序实验的数据不作为延迟承诺。内存未可靠测量。详细均值、中位数、P95、回溯、预算与失败统计见 [基准报告](V020_BENCHMARK_REPORT.md)。
