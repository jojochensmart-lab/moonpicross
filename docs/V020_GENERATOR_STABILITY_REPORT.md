# v0.2.0 生成器稳定性

原集为每尺寸种子 1–200，20×20 为 1–100。新集为每尺寸 10001–10200。两套沿用密度 45、最多 24 次和默认求解预算。每个成功样本由 MoonBit 重放并核对线索、唯一性和见证，再由独立 Python 整行候选求解器重新计数。两个后端的状态、见证和工作计数一致。重复率为同一尺寸同一批次内成功棋盘的完全重复比例。密度极值来自成功棋盘。

20×20 的 48 个失败种子均用完 24 次尝试。失败种子的 1,152 次候选中，481 次撞到预算，671 次经证明多解。增加计算预算最多只能进一步分析前者，后者需要改变采样分布或接受更多轮候选。各原因在失败种子中混合出现。当前验证支持继续把 20×20 作为探索尺寸，本轮保留预算。新组 15×15 有 3 个种子失败，200/200 的旧组结果不能外推。
